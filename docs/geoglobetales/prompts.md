# GeoGlobeTales 用のプロンプト 3 本 (参考・ネタ出し用)

このリポジトリの規約 (CLAUDE.md と maps/README.md) が優先します。
- 題名の型 (Why / How / 極端な数字) と、扱うテーマ (飛び地・国境・極端な移動・時差・地形による防衛) は使う
- 除外リストに入っている題材、および maps/README.md の「作成済み」は作らない
- 紛争中の地域 (台湾、ウクライナ、カシミール、イスラエル・パレスチナ) は避ける
- 映像は AI 動画ではなく、衛星写真の地図 + 写真カード + ものさし線で作る (maps/ の形式)

## プロンプト 1: ネタ出し

あなたは地理・国境の不思議を扱う YouTube チャンネルの企画担当です。
次の 3 つの題名の型のどれかを使い、オリジナルのネタを 10 本考えてください。

1. "Why [Country / Region] [Surprising Geographical Anomaly or Geopolitical Fact]?"
2. "How [Historical Event / Geographical Curiosity Happened]?"
3. "[Extreme Metric or Story]: [Deadliest / Most Dangerous / Strangest Geographical Phenomenon]"

除外する題材: チリの地形、アメリカの人口分布、アメリカとロシアの距離、チベット上空の飛行制限、ダリエン・ギャップ、フランスとオランダの国境 (サン・マルタン島)、ウイスキー戦争 (カナダとデンマーク)、(追加の公開済みの題材)

テーマ: 変わった国境・飛び地・領域の外れ / 地理的な制約がつくる極端な移動 / 時差や海洋・気象の不思議 / 地形が人口や防衛を決める仕組み

各ネタについて次を書く:
1. 題名 (上の型に従う)
2. 関係する国・人物・人々
3. 時代 (歴史上の時期、または現在)
4. 中心になる事実 2〜3 個 (検証できるもの)
5. 感情のフック (驚き・危険・ばかばかしさ・戦略の巧みさ など)

## プロンプト 2: 台本

あなたは地理ドキュメンタリーの台本作家です。選んだ題材で、ナレーションそのままで読める台本を書いてください。

- 口調: 速く、わかりやすく、権威はあるが話し言葉。冒頭から本題に入る (前置きなし)
- 15〜20 秒ごとに、視聴者の注意を引き直す問いを入れる
- 長さ: 60〜68 秒の短い版 (約 170〜190 語) または 8〜10 分の長い版 (約 1,200〜1,500 語)
- 構成: フック (0〜15 秒) → 場所と地形、ルール (15〜45 秒) → 原因・ねじれ (45〜90 秒) → 順を追った解説 → 締めの一文
- 書式: ナレーションは普通の文。間は [PAUSE: X sec]、地図の切り替えは [MAP CUE: ...]、重要な名前・距離・数字は太字

## プロンプト 3: 場面ごとの指示 (画像 + 動き)

あなたは地図アニメーションのアートディレクターです。台本を一文ずつ場面に分けてください。

- 見た目: 衛星写真の地図 + きれいなベクターの重ね (光る国境、黄色い経路線、赤い注意アイコン、国の塗り)
- カメラの種類を順に変える: 全体図 / 国境への寄り / 二つの地域の比較 / 斜めからの地形 / 円形の写真カードの重ね
- 各場面の出力:
  1. 画像: 最初の 1 枚の説明 (地域、角度、地図の見た目、重ね)
  2. 動き: 最初の画像からの動きだけ (カメラの動き、点滅、アイコンの出現)
  3. 話す内容: その場面で読まれる文 (ない場合は省く)
